# 🎵 Background Music (MP3 Files)

You can place your custom MP3 audio files here in this `public/audio/` directory:

1. **`bgm-main.mp3`**: The main cheerful / cute theme played during the gift reveal.
2. **`bgm-postcard.mp3`**: The special sentimental / romantic theme played when viewing the Secret Postcard!

### Note:
- If no `.mp3` files are added, the website automatically uses its built-in Web Audio API 8-bit romantic music box synthesizer without needing any external audio assets!
- When you add your `.mp3` files, name them exactly `bgm-main.mp3` and `bgm-postcard.mp3` for automatic playback.
